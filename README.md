## 🎨 Customization

### Colors
To change the color scheme, modify the CSS variables in `styles.css`:

```css
:root {
    --primary-color: #007bff;      /* Change to your preferred color */
    --secondary-color: #6c757d;
    --success-color: #28a745;
    --dark-color: #1a1a1a;
    --light-color: #f8f9fa;
    --text-color: #333;
}
```

### Content Updates
Edit the corresponding sections in `index.html`:
- **Contact Info**: Update phone, email, LinkedIn in multiple places
- **Skills**: Add/remove skill tags in the Skills section
- **Experience**: Modify experience timeline items
- **Projects**: Update project cards with new projects
- **Education**: Update educational background

### Fonts
To change fonts, modify the `font-family` in `styles.css`:

```css
body {
    font-family: 'Your Font', Arial, sans-serif;
}
```
